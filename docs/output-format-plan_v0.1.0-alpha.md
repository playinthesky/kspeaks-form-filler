# Output Format Plan v0.1.0-alpha

## Decision

Phase 1 outputs HWPX only.

PDF preview generation is excluded from Phase 1 and should be reviewed in
Phase 2 or Phase 3 after real templates are available.

## Rationale

The first release target is a stable HWPX fill pipeline. PDF preview requires
rendering and visual comparison decisions that are better made after the first
real form files arrive.
