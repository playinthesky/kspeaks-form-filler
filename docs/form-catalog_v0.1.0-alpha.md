# Form Catalog v0.1.0-alpha

Phase 1 includes ten generalized form packages:

| Form ID | Korean alias | Purpose | Public artifact status |
|---|---|---|
| `project_proposal` | 사업제안서 | Proposal skeleton | Mapping ready, skeleton placeholder only. |
| `service_contract` | 용역계약서 | Contract skeleton | Mapping ready, skeleton placeholder only. |
| `quotation` | 견적서 | Quotation skeleton | Mapping ready, skeleton placeholder only. |
| `invoice` | 청구서 | Invoice skeleton | Mapping ready, skeleton placeholder only. |
| `settlement_report` | 정산보고 | Settlement report skeleton | Mapping ready, skeleton placeholder only. |
| `staff_profile` | 직원정보 | Staff information skeleton | Mapping ready, skeleton placeholder only. |
| `progress_brief` | 중간보고 | 1-2 page progress brief skeleton | Mapping ready, skeleton placeholder only. |
| `nda` | 비밀유지 서약서 | Non-disclosure agreement pledge skeleton | Mapping ready, skeleton placeholder only. |
| `self_construction_pledge` | 자체시공 서약서 | Self-construction pledge skeleton | Mapping ready, skeleton placeholder only. |
| `integrity_pledge` | 청렴 서약서 | Integrity pledge skeleton | Mapping ready, skeleton placeholder only. |

Actual `source.hwpx` files stay in the private data repository. Slot-processed
`skeleton.hwpx` files can be committed here after source forms are generalized.
